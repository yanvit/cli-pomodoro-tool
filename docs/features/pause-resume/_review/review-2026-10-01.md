### Resolution

All three fixed in commit `fabc99b` (task T12): the interval mechanism now uses a self-rescheduling
`setTimeout` plus an explicit `activeMsInQuantum` accumulator so only real, unpaused time counts
toward the next tick regardless of how many pause/resume cycles happen in between (verified with a
multi-cycle regression test); the compact line drops the bar rather than overflowing when the
PAUSED prefix alone would exceed the terminal width; sad.md's mechanism description was corrected.
Full gate green after the fix (`npm test`: 54/54, `npm run lint` clean, `npm run build` clean).
